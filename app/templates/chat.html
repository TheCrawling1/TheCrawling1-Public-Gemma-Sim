      Automation
      Auto State — after a turn, surgical side-calls re-read the prose and sync the chosen aspects. Each is an independent model call; enable only what you need.
      Narrator — what the narrator may create on top of applying edits. Per-conversation opt-in.

      Scenario instructions

      Injected as the [Scenario] block in the system prompt. Base is the scenario-wide rules; Setup append adds the active sub-scenario's overrides. Both are pulled from the active setup root and edited in place — switching to a sibling root shows that setup's text instead.

      Scenario edits

      The active sub-scenario's state directives — [move], [outfit], [set …] — applied at root creation. One per line. Edits here change the saved state on the active root; re-applying requires a re-seed (Reset to scenario).

      Modules

      Scenario modifiers active on this branch. Activation and live-editable settings stamp to the active setup root and ride path-replay alongside the rest of branch state — siblings can have a different module mix.

      Applied edits

      Every world-state edit on the active path, newest first. Setup edits are tagged setup; narrator-emitted edits are tagged narrator. Click × on a row to revert it.

      Narrator additions

      Free-text directives the narrator translates into world-state edits, operating on the active narrator message. Use this to bring an off-cast character into the scene (e.g. "Add Rosa — she's Iris's mom"), establish a relationship without staging the entry ("Make Iris's mom be Rosa"), or rewrite the message with a state change. Off-cast characters are auto-instanced and registered on the cast list. Persists as a sibling rewrite. The per-message Narrator button uses the same prompt; this side panel is just a convenience that operates on whatever the active leaf is.

      Narrator controls

      Limits what off-cast characters the narrator sees + how brand-new characters get materialised. Use these to keep "two guys walk in" from grabbing Ash + Ben Tennyson out of the template roster.

      Character creation and dialogue-pair rewriting live under Automation → Narrator (Make characters / Make pairs).

      System prompt

      The instruction template at the top of the system block. Macros: {% raw %}{{user}}, {{char}}, {{random:a,b}}, {{roll:dN}}{% endraw %}. Pre-filled from the scenario / active setup if it provides one; otherwise leave blank for the built-in default.

      Banned phrases

      Phrases the model should never use verbatim. Rendered into the system block as a [Style discipline] instruction for both character replies and narrator rewrites. One phrase per line, case-insensitive. Global — applies to every conversation.

      Author's note

      Persistent guidance injected as a system message N turns from the bottom of the chat each request. Macros: {% raw %}{{user}}, {{char}}, {{random:a,b,c}}, {{roll:dN}}{% endraw %}. Pre-filled from the scenario / active setup if it provides one.

      Per-character notes — each applies only on that character's own turn, below the cast-wide note.

      Conversation summary

      Plain-text summary of what's happened so far. Injected as a system block right after the character card / before history. Useful when you've truncated old turns. Macros supported.

      Post-history instructions

      Final system message appended right before the model's turn. Good for "Reply in two paragraphs" style nudges.
