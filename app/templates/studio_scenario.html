    Scenario instructions

    Appended to the system block for every prompt in this scenario. Use this to set tone, ground rules, or per-scene quirks (e.g. "Milo is silent in this scene").

    First messages (per character; overrides their default)

    Add a character on the Cast tab to give them a custom first message here.

    Setups

    Branchable pre-prompts. Each setup seeds the scene differently — where characters are, who the user is, and the root narrator's opening line. The first setup is the active root by default; the rest become sibling root branches the user can switch to from the chat. The fields on the Opening tab act as the "Default" setup if no setups are listed here.

    State syntax (one directive per line, same as the narrator-edit grammar):
    [move <character_id> -> <room_id>] · [outfit <character_id> -> <outfit_id>] · [set <entity_id>.<dotted.path> = <value>] · [set user.role = "producer"]
